SalesTable:
  Description: SalesTable table from D365 F&O
  Label: "Sales orders"
  Table Rules:
  1. Orders created for customers.
Rules:
1. Order Status: Backorder: Created when the line exists but no physical action has happened. Delivered: Triggered automatically when a CustPackingSlipTrans record is created for the full Qty. Invoiced: Triggered only when the sum of Qty in the Trans (Invoice) tables matches the Qty on the Line table. A common "Data Issue" is a header showing "Open Order" while all lines are "Invoiced." This indicates a header-level synchronization failure.
2. ReceiptDateRequested: The date the customer originally requested to receive the goods at the header level.
3. ShippingDateRequested: The date the goods should leave the warehouse to meet the requested receipt date.
4. ConfirmedDlvDate: The date the system (or a user) has officially confirmed the order will be delivered. If Delivery Date Control is active (ATP/CTP). The system calculates this based on lead times; manual overrides often cause "Shipment Delay" flags in other tables.
5. If ConfirmedDlvDate > ReceiptDateRequested, the order is officially "Delayed'', or behind the schedule. (Sales Header Details) [Priority: 9]
